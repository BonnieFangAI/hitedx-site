# HITEDX — Ideas Between Events

A purpose-built interactive concept website for Hyper Island Group 6's Innovation Week project. The interface and visual system are original to this project; no site template or prebuilt theme is used.

The project explores how event audiences can become active, year-round communities. This is an independent student concept and is not an official TED or TEDx website.

Production domain: `https://hitedx.se`

## Preview locally

Open `index.html`, or serve the directory with any static HTTP server.
